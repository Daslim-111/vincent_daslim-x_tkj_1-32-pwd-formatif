proyek saya:membuat sebuah website tentang diri.

saya siswa biasa dari SMKk immanuel sedang membuat sebuah proyek berupa website yang dapat berfungsi dan dapat dilihat oleh publik.

Saya mengguanakan CSS agar hasil web saya terlihat menarik dan sesuai dengan standar yang tertera, lalu saya membuatnya di visual strudio code(VS code).

Untuk membuka dan membuat folder file baru ini saya menggunakan terminal dari laragon dengan mengetik mkdir lalu cd, setelah masuk dan filenya terbuat saya membuat lagi 4 folder didalamnya.

tentunya akan ada 1 folder khusus untuk menyimpan beberapa css, dalam menulis css saya menggunakan ketiga metode yang telah dipelajari. Ada css external, internal, inline.

ada juga folder aset untuk menyimpan berbagai perantara lain didalam web yaitu foto, vidio, icon fonts dan lain sebagainya. ada 1 file yang tidak merupakan folder yang merupakan halaman utama dari semua page, component dan style.

jadi, proyek ini benar-benar melatih kemampuan dan juga cara berpikir, oleh sebab itu proyek ini juga otomatis membutuhkan kesabaran dan ketelitian.
